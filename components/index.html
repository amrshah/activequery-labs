REUSABLE UI PATTERNS / COMMUNITY BUILT

Components you can inspect, copy and adapt.

Real interface patterns that put AQCSS utilities to work for layout, spacing, responsive sizing, typography and visual tokens, while AQJS handles DOM selection and interaction. The component-specific visual layer fills gaps; these are Labs compositions, not prebuilt upstream widgets.

AQCSS responsive prefixes are cumulative min-width rules: aq-t- starts at 600px and aq-d- at 993px. AQJS is used only through source-reviewed APIs with documented contracts; unsupported or defective helpers are intentionally not showcased.
