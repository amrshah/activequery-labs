How to test: Resize the browser or use responsive device emulation. Check 320px, 375px, 768px, 1024px, 1440px and wider. Inspect for horizontal overflow, clipped content, unreadable labels and awkward card stacking. The data is illustrative, not real analytics.

Implementation note: the page loads the upstream AQCSS distribution from GitHub's raw-content host for future comparison, but the current dashboard styling is implemented in dashboard.css. No AQCSS utility dependency is claimed for the dashboard layout yet.
