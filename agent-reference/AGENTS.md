# Instructions for AI agents using ActiveQuery Labs

1. Read `../skills/activequery-foundation/SKILL.md` first.
2. Choose AQCSS, AQJS or component engineering skill for the task.
3. Read `../docs/RESEARCH-BASELINE.md`, then verify current upstream source. The baseline is dated and may become stale.
4. Keep upstream AQCSS/AQJS source unmodified. Preserve license headers and third-party notices if source redistribution is explicitly required and permitted.
5. In code reviews, identify every AQCSS selector, AQJS API and custom addition separately.
6. Do not call a component "native AQCSS" unless it is in the upstream source.
7. Prefer HTML semantics and progressive enhancement. Test keyboard operation and responsive layouts.
8. For examples, provide runnable files, source links, setup instructions and known limitations.
9. Never claim browser or CI validation unless the corresponding test actually ran and passed.
10. When upstream versions change, update source notes and the machine-readable index together.
