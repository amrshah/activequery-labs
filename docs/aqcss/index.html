ActiveQuery CSS

A practical starting point for understanding and experimenting with the ActiveQuery CSS distribution.

Source boundary: This guide is independently maintained. The upstream repository and its bundled license notices are authoritative. The notes below summarize the upstream README and are not a substitute for inspecting the actual stylesheet.

What it is

The upstream README describes AQCSS as a mobile-first, responsive, dependency-free CSS framework. It also states that the distribution integrates W3CSS and Normalize.css. Treat those as upstream project descriptions; verify exact behavior against the current source and bundled files before relying on a particular utility or component.

Suggested learning path

  1. Read the upstream README and inspect the repository's current file tree.
  2. Identify the actual class names and layout primitives in the stylesheet; do not infer names from other frameworks.
  3. Build a small page using only documented AQCSS classes.
  4. Add custom CSS only for requirements the upstream primitives do not cover.
  5. Test at narrow mobile, tablet, laptop and wide desktop widths, including zoom and long content.

What to verify before shipping

  • Current release/version and the exact distribution URL you deploy.
  • Responsive behavior of the actual component combinations you use.
  • CSS reset and third-party bundled notices and licenses.
  • Potential class-name collisions with your own styles.
  • Accessibility: focus visibility, contrast, semantic markup and reduced-motion behavior.

This site intentionally avoids publishing an unverified utility-class catalog. A class reference should be generated from inspection of the current upstream source and checked against browser examples.
