# Contributing to ActiveQuery Labs

This is an independent, source-led documentation and experimentation project.

## Before adding a technical claim

- Link to the exact upstream repository, file or release.
- Separate what upstream says from what you personally tested.
- Avoid inventing class names, methods, events or compatibility guarantees.
- Prefer a minimal runnable example over a broad assertion.
- Record browser, viewport and version for behavior observations.

## Examples

Each example should explain:
1. What it demonstrates.
2. Which upstream version or source revision it uses.
3. Which parts are upstream and which are custom.
4. How to run and test it.
5. Known limitations and accessibility considerations.

## Changes

Keep the site static-first unless a concrete requirement justifies a build system or framework. Test narrow and wide viewports, keyboard navigation, reduced-motion preferences and basic link integrity before submitting a change.
