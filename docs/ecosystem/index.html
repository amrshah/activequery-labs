Terms encountered in the wider materials

The broader ActiveQuery discussion references terms such as AQS, AQI, AQPE and AQKISS. Read those terms in their original context and avoid assuming that an acronym alone defines a stable API, product boundary or implementation.

  • AQS: a named concept in the wider ActiveQuery architecture discussion.
  • AQI: a named concept referenced alongside the ecosystem's architecture vocabulary.
  • AQPE: a named concept referenced in the broader project materials.
  • AQKISS: a named principle or concept described in the wider materials.

How this lab documents concepts

  1. Link to the upstream artifact that introduces the term.
  2. Quote or summarize only what the source supports.
  3. Separate formal definitions from our interpretation.
  4. Record version/date when a concept changes over time.
