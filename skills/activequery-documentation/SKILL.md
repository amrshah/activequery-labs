# ActiveQuery Documentation Skill

- Verify every technical claim against current upstream source or a reproducible test.
- Record repository, branch/tag, source file and date for each researched feature.
- Preserve upstream terminology, version identifiers and license notices.
- Distinguish README claims, implementation observations, browser test results and inference.
- Include a minimal runnable example and expected output for documented APIs.
- State unsupported behavior, missing information and browser constraints.
- Keep human docs and machine-readable agent references aligned.
- Do not write a complete API reference from method names alone; inspect signatures, return values, side effects and error paths.
