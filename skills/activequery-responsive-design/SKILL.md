# ActiveQuery Responsive Design Skill

1. Inspect current AQCSS source and identify the relevant responsive selectors and media rules.
2. Start with AQCSS primitives; introduce scoped custom CSS only when needed.
3. Test 320, 360, 390, 600, 768, 992, 1024, 1280, 1440 and 1920 CSS pixel widths where applicable.
4. Test long labels, translated text, zoom, touch interaction, keyboard focus and reduced-motion preferences.
5. Check horizontal overflow, clipped controls, unreadable text, overlapping cards and excessive whitespace.
6. Record browser/version, viewport, source version and observed results.
7. Do not claim responsive behavior is proven by a single screenshot or a few viewport sizes.
