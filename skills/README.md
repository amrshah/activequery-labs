# ActiveQuery Agent Skills

These portable skills teach coding agents to research, implement, document and validate ActiveQuery using verified upstream sources.

## Skills

- [ActiveQuery foundation](activequery-foundation/SKILL.md)
- [AQCSS engineering](aqcss-engineering/SKILL.md)
- [AQJS engineering](aqjs-engineering/SKILL.md)
- [Component engineering](activequery-component-engineering/SKILL.md)

## Agent contract

Read the foundation skill first, then the domain-specific skill. Re-inspect upstream source before relying on the research baseline. Never invent API details or claim community components are upstream features.

These skills are maintained in this repository for reuse by humans and coding agents. They can be copied into an agent's supported skills directory or imported into a broader skills registry.
